# 小日常私人版

私人习惯打卡助手，当前为 React + TypeScript + Vite PWA。

## 开发

```bash
npm install
npm run dev
```

## 检查

```bash
npm test
npm run build
npm run lint
```

数据默认保存在浏览器 IndexedDB。应用支持导出和导入 JSON 备份；提醒使用浏览器 Notification API，应用完全关闭时不保证后台送达。
